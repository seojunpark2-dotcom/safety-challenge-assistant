# 안전실천 출첵

안전실천 챌린지의 화면을 확인하는 개인용 Android 도우미입니다. 스크린샷에서 확인한 공지, 출석 완료, 퀴즈 참여 완료, 룰렛 잔액과 응모 마감 문구를 접근성 노드에서 찾습니다. 설치된 안전실천 챌린지를 자동으로 인식합니다. 서비스에서 자동 참여가 허용된 기능을 확인한 후 실행할 수 있습니다.

## 다운로드 및 설치

- [APK 1.7.1 바로 다운로드](https://github.com/seojunpark2-dotcom/safety-challenge-assistant/releases/download/v1.7.1/safety-assistant-1.7.1.apk)
- [ZIP 1.7.1 바로 다운로드](https://github.com/seojunpark2-dotcom/safety-challenge-assistant/releases/download/v1.7.1/safety-assistant-1.7.1.zip) — 브라우저에서 APK가 내려받아지지 않으면 ZIP을 받아 압축을 풀고 APK를 설치하세요.

링크를 누르면 GitHub 로그인 없이 파일을 받을 수 있습니다. 이전 버전은 [GitHub 릴리스](https://github.com/seojunpark2-dotcom/safety-challenge-assistant/releases)에서 받을 수 있습니다.

APK를 스마트폰으로 옮긴 뒤, 다운로드 또는 파일 앱의 알 수 없는 앱 설치를 허용하고 APK를 엽니다. 진단용 APK는 디버그 키로 서명합니다.

## 화면 진단

1. [안전실천 챌린지](https://play.google.com/store/apps/details?id=kr.or.kosha.safetychallenge)를 설치합니다. 출첵 앱에서 자동으로 인식합니다.
2. 안전실천 출첵 설정에서 접근성 권한을 켭니다. 옵션에서 프라이버시 커튼과 출석 결과 알림을 따로 켤 수 있습니다.
3. 대상 앱에서 볼 화면을 연 뒤 도우미에서 **최근 화면 진단 결과 보기**를 누릅니다.

대상 앱의 보이는 접근성 문구를 메모리에서 검사하고 판정과 구조를 표시합니다. 이미지에만 있는 버튼과 표시에는 기기 확인이 필요합니다. 3,000포인트 버튼이 표시돼도 실제 응모 가능 여부는 앱에서 확인하세요.

## 자동 실행

- 출석, 퀴즈, 룰렛을 각각 실행하거나 예약 대상에 추가할 수 있습니다.
- 사진에서 정답이 확인된 크레인 문항은 기존 정답을 사용합니다. 새 문항은 Gemini로 판단합니다. 앱에 관련 공식 자료가 있으면 함께 전달합니다.
- 룰렛 참여를 실행하면 잔액이 3,000포인트 이상이고 화면에 3,000포인트 참여 버튼이 있을 때 하루 한 번 시도합니다. 응모가 마감됐거나 비용이 다르면 중단합니다.
- 출석, 제출, 룰렛 버튼을 누르기 전에 해당 날짜의 시도를 기록합니다. 응답을 읽지 못하거나 앱을 다시 시작해도 같은 날 다시 누르지 않습니다.
- 예약은 기본 오전 9시이며 Android 상태에 따라 지연될 수 있습니다. 화면이 꺼져 있으면 예약 화면을 열어 깨웁니다. 보안 잠금은 Android 화면에서 최대 30초 동안 사용자 인증을 기다립니다. 성공 후에만 출석을 진행합니다.
- 실행 뒤에는 원래 앱을 다시 열거나 홈으로 돌아갑니다. 처음 화면이 꺼져 있었다면 Android 9 이상에서 화면 잠금 작업을 요청합니다. 새 대상 앱 작업은 최근 앱에서 제외하되, Android 제약으로 이전에 존재하던 대상 앱 카드는 남을 수 있습니다.
- 실제 기기에서 접근성 버튼, 스크롤, 결과 문구를 검증해야 합니다. 이미지로만 표시된 버튼은 사용자가 직접 조작합니다.

## AI 퀴즈 설정

[Google AI Studio](https://aistudio.google.com/app/apikey)에서 발급한 Gemini API 키를 앱의 **Gemini API 키** 항목에 입력하고 **키 저장**을 누릅니다. 키는 기기에서 Android Keystore로 보호해 저장하며 앱에서 삭제할 수 있습니다. 결제를 연결하지 않은 무료 프로젝트의 키를 사용하면 무료 한도에서 작동합니다. 앱은 기본 텍스트 요청만 보내며 Google 검색 도구를 호출하지 않습니다.

새 문항을 풀 때는 접근성으로 읽은 문제 문장과 주제가 일치하는 법령 요약을 Gemini로 전송합니다. 자료는 국가법령정보센터의 산업안전보건기준에 관한 규칙 제32조, 제146조, 제301조를 바탕으로 작성했습니다. 자료가 있으면 응답이 해당 조문을 인용해야 제출을 시도합니다. 자료가 없으면 문제만 보내며, 답과 이유가 명확하면 제출을 시도합니다. 이 경우 실제 정답이 확인된 것은 아니며 실행 기록에 공식 근거 없는 Gemini 추론으로 표시합니다. Gemini가 판단을 보류하거나 요청 한도에 걸리면 실행 기록을 남기고 중단합니다. 접근성 문구가 없는 이미지 퀴즈는 수동으로 진행합니다.

## 빌드

Android SDK 35와 JDK 17 이상이 필요합니다. Windows에서 한글 경로로 테스트가 실패하면 영문 경로에서 실행합니다.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

결과는 `app/build/outputs/apk/debug/`에 생성됩니다.
